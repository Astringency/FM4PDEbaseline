# Large-Scale External Baseline Experiments

## Design

The default paper experiment design is split into main results and ablations. Main results are not a sensor/noise/mode full grid. They vary only compatible `baseline x PDE x seed`.

Sparse main-result rows use one standard sparse setting:

- `num_sensors=500`
- `sensor_mode=random`
- `noise_level=0.0`

Sensor count, observation noise, sensor placement, train size, and runtime budget are separate ablation matrices. Each ablation changes one factor by default. `full_all` and other exhaustive grids are legacy/debug configs only and are not generated by the default build script.

Formal paper-mode commands generated here do not include `--dry-run`, `--synthetic-data`, `--allow-synthetic-fallback`, or `--prefer-test`.

## Default Matrices

`scripts/experiments/00_build_matrices.sh` writes:

- `OUT_ROOT/matrices/sanity_main.jsonl`
- `OUT_ROOT/matrices/main_results.jsonl`
- `OUT_ROOT/matrices/sensor_count_ablation.jsonl`
- `OUT_ROOT/matrices/noise_ablation.jsonl`
- `OUT_ROOT/matrices/sensor_mode_ablation.jsonl`
- `OUT_ROOT/matrices/time_varying_sensor_ablation.jsonl`
- `OUT_ROOT/matrices/runtime_budget_ablation.jsonl`
- `OUT_ROOT/matrices/train_size_ablation.jsonl`

It does not build `full_all.jsonl`.

## Task Groups

Main-result groups:

- `full_forward_main`: `forward`, `fno/deeponet/ifno`.
- `full_inverse_main`: `inverse`, `fno/deeponet/ifno`.
- `sparse_solution_main_amortized`: `sparse_solution`, `recfno/senseiver/voronoicnn/fno/deeponet`, fixed sparse setting.
- `sparse_solution_main_physics`: `sparse_solution`, `pinn_sparse/pc_bnn/pde_opt/var4d/vivid`, fixed sparse setting. `var4d/vivid` skip static PDEs.
- `sparse_inverse_main`: `sparse_inverse`, `recfno/senseiver/voronoicnn/fno/deeponet`, fixed sparse setting. Per-instance baselines are not included.

Ablation groups:

- `sensor_count_ablation`: varies only `num_sensors`.
- `noise_ablation`: varies only `noise_level`.
- `sensor_mode_ablation`: varies only `sensor_mode`.
- `time_varying_sensor_ablation`: varies only time-varying sensor count on `nsnonbounded/burger/reaction_diffusion/shallow_water`.
- `runtime_budget_ablation`: varies each per-instance method's relevant budget, without crossing `steps`, `refine_steps`, and `particles`.
- `train_size_ablation`: varies only `train_size`.

Set `FULL_ABLATION_ALL=1` to expand ablations beyond the representative PDE/baseline defaults. This still keeps the declared ablation factor as the only varied experimental factor.

## Compatibility And Skips

Compatibility is centralized in [baselines/experiment_matrix.py](../baselines/experiment_matrix.py). Unsupported combinations are not run. They are written to `OUT_ROOT/skipped_combinations.jsonl` and matrix-specific `*_skipped.jsonl` files with a `reason` and `would_have_expanded` count.

Key skip rules:

- `DiffusionPDE` and FM4PDE internal ablations are outside this external-baseline matrix.
- `ifno` is full `forward/inverse` only.
- `var4d/vivid` run only on time-dependent PDEs.
- `time_varying` sensors require trajectory-compatible PDEs and adapted baselines.
- `sparse_inverse` skips per-instance baselines because they would need a PDE forward solve from predicted coefficients or initial state to observed solution sensors.

## Recommended Run Order

Step 1:

```bash
bash scripts/experiments/00_build_matrices.sh
```

Step 2:

```bash
DATA_ROOT=/path/to/PDEdata OUT_ROOT=outputs/baselines_large \
bash scripts/experiments/01_run_sanity_main.sh
```

Step 3:

```bash
DATA_ROOT=/path/to/PDEdata OUT_ROOT=outputs/baselines_large \
bash scripts/experiments/02_run_main_results_local.sh
```

Use `TASK_GROUPS="full_forward_main sparse_solution_main_amortized"` to run a subset locally. `N_JOBS` defaults to `1`.

Step 4:

```bash
ABLATION=sensor_count_ablation \
bash scripts/experiments/04_run_ablation_local.sh
```

Step 5:

```bash
bash scripts/experiments/06_aggregate_main_results.sh
bash scripts/experiments/07_aggregate_ablations.sh
```

## SLURM

Main results:

```bash
OUT_ROOT=outputs/baselines_large DATA_ROOT=/path/to/PDEdata \
MAX_ARRAY_CONCURRENT=16 \
bash scripts/experiments/03_submit_main_results_slurm.sh
```

Ablations:

```bash
ABLATION=noise_ablation OUT_ROOT=outputs/baselines_large DATA_ROOT=/path/to/PDEdata \
MAX_ARRAY_CONCURRENT=16 \
bash scripts/experiments/05_submit_ablation_slurm.sh
```

Useful SLURM env vars: `PARTITION`, `TIME`, `CPUS_PER_TASK`, `MEM`, `GRES`, `JOB_NAME`.

## Resume, Status, Retry

Each run writes:

`run.started`, `run.running`, `run.done`, `run.failed`, `command.txt`, `env.txt`, `stdout.log`, `stderr.log`, `metadata.json`, and `run.status.json`.

`05_run_one.sh` skips completed runs unless `FORCE=1`. It skips failed runs unless `RETRY_FAILED=1`. Stale running locks are controlled by `LOCK_TIMEOUT_SECONDS`.

Status:

```bash
OUT_ROOT=outputs/baselines_large bash scripts/experiments/08_status.sh
```

Retry failed rows:

```bash
MATRIX=outputs/baselines_large/matrices/main_results.jsonl \
OUT_ROOT=outputs/baselines_large RETRY_LIMIT=3 \
bash scripts/experiments/09_retry_failed.sh
```

## Legacy Exhaustive Grids

`configs/experiments/full_all.yaml`, `core.yaml`, and `time_varying.yaml` are marked `legacy: true`. They are retained for debugging only and are not used by default paper experiments.
